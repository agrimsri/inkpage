# Keyboard Shortcuts Specification

| Shortcut | Action | Description |
|---|---|---|
| `Ctrl+N` | New Page | Creates a new page in the current section |
| `Ctrl+Shift+N` | New Section | Creates a new section in the current notebook |
| `Ctrl+E` or `Ctrl+F` | Focus Search | Opens the search bar and focuses the query field |
| `Ctrl+K` | Insert / Edit Link | Adds a hyperlink or `[[page link]]` |
| `Ctrl+Shift+K` | Cycle Tag | Cycles container tags (To-Do -> Important -> Question -> None) |
| `Ctrl+1` | To-Do Tag | Toggles checkbox / task tag on the current outline item |
| `Ctrl+2` | Important Tag | Toggles star / important tag on current item |
| `Ctrl+3` | Question Tag | Toggles question tag on current item |
| `Ctrl+Z` | Undo | Undoes the last canvas/outline/stroke modification |
| `Ctrl+Y` / `Ctrl+Shift+Z` | Redo | Redoes the last undone operation |
| `Ctrl+B` | Bold | Toggles bold text formatting |
| `Ctrl+I` | Italic | Toggles italic text formatting |
| `Ctrl+U` | Underline | Toggles underline text formatting |
| `Ctrl+Shift+H` | Highlight | Toggles text highlight |
| `Tab` | Indent Outline | Indents outline item one level deeper |
| `Shift+Tab` | Outdent Outline | Un-indents outline item one level up |
| `Space + Drag` | Pan Canvas | Drags the viewport across the infinite 2D canvas |
| `Ctrl + Scroll` | Zoom Canvas | Zooms in/out centered on cursor |
| `Ctrl+0` | Reset Zoom | Resets canvas zoom to 100% |
| `P` | Pen Tool | Selects freehand pen tool |
| `H` | Highlighter Tool | Selects freehand highlighter tool |
| `E` | Eraser Tool | Selects stroke eraser tool |
| `V` / `S` | Select / Pointer | Selects item selection/move tool |
| `T` | Text Tool | Activates text container placement tool |
